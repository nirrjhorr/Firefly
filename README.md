# Firefly

A 100% offline, privacy-critical mental wellbeing companion designed with trauma-informed, low-stimulation principles.

## Features

- **Stanley-Brown Safety Plan**: Clinical-grade crisis response with rapid panic blank mechanism and instant SOS overlay.
- **Affect Check-In**: Pure deterministic recommendation engine with low-friction mood and energy logging.
- **Respiration & Sensory Grounding**:
  - Evidence-backed **Cyclic Sighing** (4s inhale / 8s exhale) with smooth, organic `CustomPainter` bloom visualizer.
  - Interactive **5-4-3-2-1 Sensory Grounding** mode with tactile feedback and penalty-free pacing.
  - Offline ambient soundscapes (synthesizer drone, gentle rain, acoustic chimes).
- **Zero Cloud Leakage**: Local-first architecture protected by encrypted local storage (SQLCipher + Drift).
- **Accessible & Trauma-Informed UI**: Dark canvas foundation, sage accents, high-contrast clarity, and system reduced-motion compliance.

## Tech Stack

- **Flutter & Dart 3**
- **State Management**: Riverpod 2
- **Routing**: GoRouter
- **Local Database**: Drift + SQLCipher
- **Audio & Haptics**: just_audio, custom hardware adapters
