# Story 3.5: Affect Result Card & Home Screen Integration

Status: done

## Story Description
As a user who just completed a check-in,
I want a clear, calm recommendation result card with an immediate single-tap CTA and an alternative options drawer,
So that I am guided directly to the right relief without decision paralysis.

## Acceptance Criteria
1. Displays `AffectResultCard` with:
   - Primary action title (e.g. "Slowing down with breath").
   - 1–2 sentence compassionate description.
   - Duration badge (e.g. "~2 mins").
   - Single prominent primary CTA navigating to destination route.
2. "Try something else" expandable drawer with 3 alternative suggestions.
3. Check-in summary integrated into Home screen with "Check in again" option.
