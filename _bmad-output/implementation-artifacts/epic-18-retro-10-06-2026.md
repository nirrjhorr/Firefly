## 1. Executive Summary

Epic 18 brings Firefly's core Single-Session Intervention (SSI) promise to life. Anchored in Schleider et al. (2025) and Baumel et al. (2019), the One-Session Reset offers users in acute distress a complete, self-contained 5-minute regulation journey that delivers immediate value in a single sitting.

---

## 2. Key Delivered Capabilities

1. **5-Step Evidence-Based State Machine:**
   - Sequential progression: Anchor (affect labeling) → Regulate (90s somatic settle) → Reframe (self-compassion) → Commit (behavioral activation micro-action) → Complete (nervous system shift rating).
   - Bi-directional navigation allowing users to move back without state corruption.
2. **Apple-Inspired Low-Cognitive-Load UI (`ResetScreen`):**
   - 5-dot subtle progress bar.
   - 90-second animated rhythmic pulse bloom with play/pause and gentle phase cues.
   - Touch-friendly action selectors ($\ge 56\text{dp}$).
   - Persistent SOS overlay on all steps.
3. **Universal App Integration:**
   - Registered at `/home/reset` and root modal `/reset`.
   - Accessible via check-in home card and acute distress modal.
   - Seeded in `curated_activities.json` bringing total catalog to 71 practices.

---

## 3. Retrospective Insights

### What Went Well
- **Pure Dart Headless Isolation:** The domain models (`ResetPhase`, `ResetDistressAnchor`, `ResetSession`) and repository are completely decoupled from UI widgets, allowing complete headless verification.
- **Single-Session Delivery:** Eliminates user burden of multi-step programs by packing maximum evidence-informed relief into under 5 minutes.
