# Story 3.4: Affect Check-In Screen UI

Status: done

## Story Description
As a user experiencing acute emotions,
I want an intuitive, low-friction check-in screen with moon-phase tiles and peaceful sliders completable in < 30 seconds (≤ 5 taps),
So that I can register how I feel without feeling evaluated or overwhelmed.

## Acceptance Criteria
1. Displays 5 `MoodTile` components (Heavy, Low, Here, Light, Open) with calm moon-phase visuals and selected glow.
2. `EnergySlider` with "Still → Moving" labels and gentle interaction.
3. 5-dot selectors for anxiety and loneliness levels (non-numerical, peaceful dots).
4. Full-width 56dp "I'm here" sage button that triggers submission.
5. All tap targets ≥ 56dp and accessible with screen readers.
