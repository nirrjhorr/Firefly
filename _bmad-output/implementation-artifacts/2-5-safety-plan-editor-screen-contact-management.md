# Story 2.5: Safety Plan Editor Screen & Contact Management

Status: done

## Story Description
As a user preparing for future difficult moments,
I want a full-screen editor where I can add, modify, and reorder my warning signs, coping strategies, and contacts,
So that my safety plan accurately reflects what truly helps me.

## Acceptance Criteria
1. `SafetyPlanEditorScreen` provides full editing for each of the 6 steps.
2. Add / edit / remove contacts with name, phone number, relationship, and professional flag.
3. Add / remove warning signs and coping activities.
4. Auto-save functionality ensures edits are preserved without anxiety-inducing "Discard unsaved changes" dialogues.
5. All input fields have accessible labels and touch targets ≥ 56dp.
