### Activation Commands
As these skills are already present in the `.agent/skills/` directory from the workspace bootstrap, they are inherently active for the agent. If they were to be copied from a global registry, the command would be:
```powershell
Copy-Item -Path "C:\Users\mdhas\.gemini\config\skills\*" -Destination ".agent\skills\" -Recurse
```
